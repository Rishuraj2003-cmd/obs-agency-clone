# Obys Agency Website Clone

A visually rich, animated, and interactive clone of the Obys Agency website. This project replicates the smooth scroll effects, cursor animations, and creative visuals of the original design using modern web technologies.

## ✨ Features

- Smooth scrolling with **Locomotive Scroll**
- Scroll-based animations using **GSAP (GreenSock Animation Platform)**
- Custom cursor with magnetic effects
- Interactive video player
- Creative layout with layered sections and animated text
- Responsive design for various screen sizes
- Stylish use of custom fonts and transitions

## 🛠 Tech Stack

- **HTML5**  
- **CSS3** (with animations & responsive styles)  
- **JavaScript (ES6)**  
- **GSAP & ScrollTrigger**  
- **Locomotive Scroll**  
- **Shery.js** (for magnetic and mouse effects)  
- **RemixIcon** (for icons)
